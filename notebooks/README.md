# Notebooks

Naming:

- `w01_eda.ipynb`
- `w02_baselines.ipynb`
- `w03_survival.ipynb`
- `w04_mlp.ipynb`
- `w05_transformer_...`

Each notebook should start with a short markdown block:

1. **Question** — what am I testing this week?
2. **Data** — which file, how many rows/features, train/test split.
3. **Method** — what model/preprocessing.
4. **Result** — the key number or figure.
5. **Limitation** — what could be wrong.

Before committing:

- Restart kernel and run all cells.
- Remove exploratory dead ends or move them to an appendix section.
- Make sure the notebook runs from a clean `data/raw/` download.
